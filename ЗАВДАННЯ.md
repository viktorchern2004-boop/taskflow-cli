# ЗАВДАННЯ

## Застосунок

**Назва:** TaskFlow CLI – локальний менеджер особистих завдань.

**Опис:** консольна програма для створення, перегляду, редагування, фільтрації та видалення завдань без необхідності розгортати сервер.

**Цільові користувачі:** студенти та користувачі, яким потрібен простий локальний облік справ.

**Функціональні вимоги:**
1. Створення завдання з назвою та необов'язковим описом.
2. Перегляд списку завдань та деталей конкретного завдання за ID.
3. Редагування назви й опису завдання.
4. Зміна статусу (`todo`, `in_progress`, `done`).
5. Призначення пріоритету (`low`, `medium`, `high`).
6. Встановлення строку виконання `YYYY-MM-DD`.
7. Фільтрація за статусом та пріоритетом.
8. Видалення завдання з підтвердженням.
9. Збереження завдань між запусками в локальному JSON.

**Стек:** Python 3.11+, стандартні бібліотеки `argparse`, `json`, `pathlib`, `datetime`, `uuid`, `pytest` для тестів, Git та GitHub.

Детальні вимоги і критерії перевірки: [docs/app-requirements.md](docs/app-requirements.md).

## Обрана агентна IDE

**Visual Studio Code + GitHub Copilot Chat (Agent mode).** Підтримка роботи з файлами, Git, терміналом, MCP-серверами, проєктними інструкціями, skills, агентними ролями та hooks (залежно від версії й режиму). Конкретні можливості й ліміти перевіряються перед реалізацією відповідних практичних.

## Мета Agent Harness

Забезпечити контрольоване середовище для AI-агента, який допомагає розробляти TaskFlow CLI: отримує архітектурні знання через MCP-конектор до окремого Obsidian vault, дотримується guardrails та використовує формалізовані skills.

## Цільові задачі агента

1. Генерувати та вдосконалювати невеликі модулі застосунку за вимогами.
2. Створювати й виконувати автоматичні тести для нових модулів.
3. Перевіряти зміни коду на відповідність вимогам і guardrails.
4. Оновлювати технічну документацію після змін.
5. Формувати ADR-записи й синхронізувати їх із vault через MCP.

## Репозиторії

- **Застосунок і harness:** `taskflow-cli` (цей репозиторій).
- **База знань Obsidian:** `taskflow-knowledge-base` (окремий репозиторій за межами робочої директорії застосунку).

Повні вимоги до Agent Harness: [docs/harness-requirements.md](docs/harness-requirements.md).
